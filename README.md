## Descripción
Este proyecto contiene una página web con recursos útiles para aprender informática y programación.

## Objetivo
Reunir enlaces a páginas educativas sobre HTML, CSS, GitHub y Python.

## Archivos del proyecto
- `index.html`: contiene la estructura de la página web.
- `style.css`: define los estilos y la apariencia visual.
- `README.md`: describe el proyecto y sus archivos.

## Recursos incluidos
- HTML
- CSS
- GitHub
- Python

## Tecnologías utilizadas
- HTML5
- CSS3
- GitHub
